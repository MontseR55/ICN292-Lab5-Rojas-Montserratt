# ICN292 - Laboratorio 5 - Base andesbike

Laboratorio de consultas SQL (LEFT JOIN, auto-joins y subconsultas) sobre la base de datos de la cadena de tiendas de bicicletas Andes Bike.

**Estudiante:** Montserratt Rojas
**Asignatura:** ICN292 - Universidad Técnica Federico Santa María

## Contenido del repositorio

| Archivo | Descripción |
|---|---|
| `ICN292-Lab5-Rojas-Montserratt.sql` | Script con la creación de las cuatro tablas, la carga oficial y las diez consultas |
| `ICN292-Lab5-Rojas-Montserratt.pdf` | Informe con el código de cada consulta y la captura de MySQL Workbench |
| `ICN292-Lab5-Rojas-Montserratt.docx` | Mismo informe en Word |
| `ICN292-Lab5-Rojas-Montserratt-ER.png` | Modelo entidad-relación obtenido con Reverse Engineer |

## Cómo ejecutar el script

1. Abrir MySQL Workbench y conectarse al servidor local.
2. Abrir `ICN292-Lab5-Rojas-Montserratt.sql`.
3. Ejecutar todo el script (rayo, o `Ctrl+Shift+Enter`). El script elimina y vuelve a crear la base `andesbike`, así que se puede correr cuantas veces se quiera.

La carga oficial deja 4 tiendas, 8 vendedores, 8 modelos y 18 ventas (35 unidades, monto total 16.969.650).
